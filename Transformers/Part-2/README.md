# DataOrbitAI – Transformers Part 2

## Practical Python Implementation with Hugging Face

This module demonstrates how Transformer models work internally using Python and Hugging Face Transformers.

### Topics covered
- Pretrained Transformer models
- Tokenization and token IDs
- Token embeddings and positional information
- Transformer layers and attention heads
- Hidden states and attention outputs
- Logits and next-token prediction
- Autoregressive text generation

### Project files
- `transformer_part2_demo.py` – Python demonstration
- `transformer_part2_demo.ipynb` – Interactive notebook
- `capture_outputs.py` – Output capture utility
- `requirements.txt` – Required dependencies

### Prerequisites
Python and basic Python programming knowledge.

### Installation

```bash
pip install -r requirements.txt
```

### Run the demonstration

```bash
python transformer_part2_demo.py
```

### Jupyter Notebook

Open `transformer_part2_demo.ipynb` in Jupyter Notebook or VS Code.

Refer to the code and notebook for the complete learning experience.
